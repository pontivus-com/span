# Support

Span is a pre-1.0 open-source project maintained by Rolf Streefkerk. Support is
best-effort and community-based: there is no service-level agreement, no
guaranteed response time, and no commercial support offering.

## Supported versions

Security and correctness fixes land on the current `0.6.x` line. Older lines are
not maintained. Upgrade to the latest release before reporting a problem.

## Where to ask

| Question | Channel |
| --- | --- |
| Bug report | [GitHub issue](https://github.com/pontivus-com/span/issues) using the bug template |
| Feature request | [GitHub issue](https://github.com/pontivus-com/span/issues) using the feature template |
| Usage and design question | [GitHub issue](https://github.com/pontivus-com/span/issues) (no separate forum) |
| Security vulnerability | [Private report](SECURITY.md) — never a public issue |
| Contribution | [CONTRIBUTING.md](CONTRIBUTING.md) |

## What to include

A useful report contains:

- the Span version and how it was installed (checkout or wheel);
- operating system, Python version, and coding agent;
- the approximate repository size and language mix;
- the operation you called, the input, and the response;
- a minimal reproduction when one is possible.

Do not paste secrets, credentials, or proprietary source. Span runs locally and
does not need them to reproduce a problem.

## What to expect

Issues are read and triaged as time allows. A response may take days or longer,
and some reports may be answered with a documented limitation rather than a fix.
Security reports are handled first; see [SECURITY.md](SECURITY.md) for the
private reporting flow.

If Span is not answering your question, the [scope](docs/scope.md) and
[FAQ](docs/faq.md) pages may already state whether the behaviour is intended.
