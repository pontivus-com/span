# Span brand assets

Primary colors
- Graphite: #111B21
- Teal: #00ADBC
- White: #FAFCFC

Recommended use
- `span-logo.svg`: canonical scalable full logo.
- `span-icon.svg`: canonical scalable icon-only mark.
- `span-logo-full-color-light.png`: transparent logo for light surfaces.
- `span-logo-full-color-dark.png`: transparent white/teal logo for dark surfaces.
- `span-logo-mono-black.png` / `span-logo-mono-white.png`: one-color contexts.
- `span-icon-*.png`: repository avatar, app icon and favicon sizes.
- `span-favicon.ico`: browser favicon.
- `span-social-card-1200x630.png`: Open Graph/social card.
- `span-product-concept-1600x900.png`: website explainer visual.

Clear-space rule
Keep at least one node-diameter of clear space around the mark or lockup.

Do not
- stretch or skew the logo;
- recolor the teal independently;
- add shadows or effects to the primary logo;
- place the dark full-color lockup on a background without sufficient contrast.
